### 変更内容

#### 新機能
- **`--forward-subagent-text` フラグと `CLAUDE_CODE_FORWARD_SUBAGENT_TEXT` 環境変数の追加**
  - 関連: `--forward-subagent-text` / `CLAUDE_CODE_FORWARD_SUBAGENT_TEXT`
  - ストリーム JSON 出力にサブエージェント テキストと思考を含めることができます。

#### 改善
- **パーミッションプレビューの修正**
  - 関連: パーミッションプレビュー
  - パーミッションプレビューが双方向オーバーライド、ゼロ幅、類似の引用符文字を中和しない問題を修正しました。
- **自動モードのオーバーライド問題の修正**
  - 関連: 自動モード
  - PreToolUse フックの `ask` 決定が尊重されるようになりました。

#### バグ修正
- **並列 Claude Code セッションの同時ログアウト問題の修正**
  - 関連: クレデンシャルストア
  - 並列 Claude Code セッションが同時にログアウトする問題を修正しました。
- **プラグイン MCP サーバーの再接続問題の修正**
  - 関連: MCP サーバー
  - プラグイン MCP サーバーがアイドル状態のウェブセッション後に再接続されない問題を修正しました。
