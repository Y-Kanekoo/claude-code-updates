# 敵対的検証チェックリスト（claude-code-updates）

PRごとに下の表をコピーして結果を書きます（PR本文に貼ってもよい）。空欄は未確認とみなします。該当しない観点は「対象外（理由）」と書きます。観点の詳細は development-hub の [敵対的検証の標準](https://github.com/Y-Kanekoo/development-hub/blob/main/docs/adversarial-verification.md) を参照してください。

## 必須観点

| 観点 | 攻撃した内容 | 結果 | 追加したテスト |
| --- | --- | --- | --- |
| 悪意ある入力（空・巨大・制御文字・パストラバーサル・注入・不正JSON） | | | |
| テストの弱体化（削除・skip・期待値の緩和・常に成功するモック・閾値の引き下げ） | | | |
| 権限・秘密値（権限なしの操作、秘密値のコミット・ログ・エラー表示） | | | |
| 依存関係（追加理由・ロックファイル・提供元・ライセンス・インストール時スクリプト） | | | |
| 失敗・リトライ（タイムアウト・5xx・途中切断、上限とバックオフ） | | | |
| 冪等性（二重送信・リトライ・途中失敗後の再実行） | | | |
| ログの機密情報（トークン・メールアドレス・個人のパス・本文） | | | |

## 推奨観点（大きな変更では必須）

| 観点 | 攻撃した内容 | 結果 | 追加したテスト |
| --- | --- | --- | --- |
| レート制限（429・Retry-After・自分の公開処理の上限） | | | |
| 並行実行（競合・ロック・一時ファイル） | | | |
| 資源の枯渇（巨大入力・無限ループ・リーク） | | | |
| 時刻・地域（タイムゾーン・夏時間・ロケール） | | | |
| 後方互換（旧データ・設定の削除） | | | |

## 判定

- [ ] 必須観点がすべて埋まっている
- [ ] 見つかった問題は修正し、再発を防ぐテストを追加した
- [ ] 手戻りは knowledge/ に記録した
