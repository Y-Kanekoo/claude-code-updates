## 変更内容

### 新機能
<!-- sources:R1 -->
- **`serverToolUses` が mod の `turn.step` フックの結果に追加**
  - 関連: `serverToolUses`
  - `serverToolUses` にはツールが自身（アドバイザー）を呼び出した情報が含まれ、id、name、input、start、end が提供されます。
<!-- sources:R2 -->
- **`agentId` がプラグインフックの `tool.check` イベントに追加**
  - 関連: `agentId`
  - `tool.check` イベントでサブエージェントの権限チェックとメインセッションを区別できるようになりました。
<!-- sources:R3 -->
- **`ceiling` が mod の `tool.check` フックで使用可能に**
  - 関連: `ceiling`
  - `ceiling` は組織がツールに対して要求する承認レベルを示します。
<!-- sources:R4 -->
- **`ThemeKey` と `Color` 型がプラグインフックの型定義に追加**
  - 関連: `ThemeKey` / `Color`
  - エディタが mod の描画で使用できるテーマカラーを一覧表示できるようになりました。
<!-- sources:R5 -->
- **`claude plugin validate` に各フックの `.catch` 有無が表示**
  - 関連: `gatingHooks`
  - ゲートサイトで登録されたフックが `gatingHooks` 配列で `.catch` の有無と共に JSON 出力されます。
<!-- sources:R6 -->
- **Claude アプリゲートウェイのサインイン承認ページに Deny ボタンが追加**
  - 関連: `Deny button`
  - Deny ボタンで保留中のサインインを即座に終了し、端末側が数秒で停止します。
<!-- sources:R7 -->
- **セッション名でのコマンド指定を追加**
  - 関連: `claude attach` / `claude logs`
  - セッション名を ID の代わりに `claude attach <name>` と `claude logs <name>` に使用できるようになりました。
<!-- sources:R8 -->
- **Managed Agents のオンボーディング URL 指定を追加**
  - 関連: `managed-agents-onboard`
  - `/claude-api managed-agents-onboard <url>` により、Managed Agents パターンを URL で設定できるようになりました。
<!-- sources:R9 -->
- **Managed Agents のクイックスタートテンプレート作成を追加**
  - 関連: `managed-agents-onboard`
  - `/claude-api managed-agents-onboard <quickstart-name>` により、Console のクイックスタートテンプレート（例: deep-researcher）を ant CLI で構築できるようになりました。
<!-- sources:R10 -->
- **外部ファイルリンクに対する警告を追加**
  - 関連: `managed settings file` / `link`
  - Managed settings ファイルが管理フォルダ外のファイルへのリンクの場合、警告が表示されるようになりました。
<!-- sources:R11 -->
- **/status と doctor 警告の追加**
  - 関連: `/status` / `doctor` / `sandbox allowRead` / `allowed domains`
  - Managed settings がユーザー設定の sandbox allowRead パスや許可ドメインを無視した場合、/status と doctor に警告が表示されます。
