## 変更内容

### 新機能
<!-- sources:R1 -->
- **WebFetchツールを無効化する環境変数 `CLAUDE_CODE_DISABLE_WEB_FETCH` を追加**
  - 関連: `CLAUDE_CODE_DISABLE_WEB_FETCH`
  - 環境変数 `CLAUDE_CODE_DISABLE_WEB_FETCH` を設定すると、WebFetchツールが無効になります。
<!-- sources:R2 -->
- **デスクトップアプリ起動オプション `claude --desktop` を追加**
  - 関連: `claude --desktop`
  - `claude --desktop` を使用すると、現在のディレクトリでClaudeデスクトップアプリが起動し、`--continue` や `--resume <id>` と併用できます。
<!-- sources:R3 -->
- **`claude plugin configure <plugin>` コマンドを追加**
  - 関連: `claude plugin configure`
  - このコマンドでプラグインのオプションを表示し、未設定項目を確認、`--values-stdin` で標準入力から新しい値を保存できます。
<!-- sources:R4 -->
- **`claude plugin install --config` にサーバー設定 `<server>.<key>=<value>` を追加**
  - 関連: `claude plugin install --config`
  - インストール時にMCPサーバー固有の設定を指定でき、インストール後に `/plugin` → Configure にアクセスせずに起動できます。
<!-- sources:R5 -->
- **`allowedProviders` 設定を追加**
  - 関連: `allowedProviders`
  - `allowedProviders` により、使用可能なAPIプロバイダー（Anthropic API など）を制限できます。
<!-- sources:R6 -->
- **`CLAUDE_CODE_NONSTREAMING_TIMEOUT_RETRIES` 環境変数を追加**
  - 関連: `CLAUDE_CODE_NONSTREAMING_TIMEOUT_RETRIES`
  - この変数で、タイムアウトした非ストリーミングフォールバックリクエストの再送回数上限を設定できます。
