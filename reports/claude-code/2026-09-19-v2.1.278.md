## 変更内容

### 新機能
<!-- sources:R2 -->
- **/status に Auto mode server 行が追加**
  - 関連: `/status`
  - /status エンドポイントに「Auto mode server」行が追加され、現在のセッションでサーバー側分類器が使用されているかを確認できます。

### 仕様変更
<!-- sources:R1 -->
- **自動モードがサーバー側分類器をデフォルトに変更**
  - 関連: `CLAUDE_CODE_AUTO_MODE_SERVER`
  - Claude API と Enterprise ユーザー、Bedrock、Vertex、Foundry、ゲートウェイで自動モードがサーバー側分類器にデフォルト変更され、分類器のオーバーヘッド料金が発生しません。オプトアウトは環境変数 CLAUDE_CODE_AUTO_MODE_SERVER=0 で行い、課金が発生するフォールバック時に警告が表示されます。
